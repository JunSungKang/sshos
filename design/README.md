# Design Assets

The current original sshOS bow source is [the SVG](../src/renderer/assets/sshos-bow.svg). The runtime uses [a local PNG](../src/renderer/public/sshos-icon.png); executable icon containers are [ICO](../build/icons/sshos.ico) and [ICNS](../build/icons/sshos.icns). The motif combines a dark-yellow decorated recurve bow and long crimson feather-like ornaments on dark chocolate.

Exploration files, production prompts, mockup specifications and sprint design records stay local and ignored. Published screenshots of synthetic fixtures are not evidence of native operating-system or real server acceptance. See [the UI architecture](../docs/developer/architecture/desktop-interaction.md) for implemented ownership and interaction.
