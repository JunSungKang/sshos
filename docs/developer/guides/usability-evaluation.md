Use the [Product Plan](product-plan.md) for tasks, baseline and analysis. Include connect/browse/view/transfer/execute/slow-response/disconnect. Record help requests, unsupported tasks and outcome interpretation. Keep insufficient opportunity separate from rejection; never select only successful cases. Do not collect real credentials/files. Agree disclosure scope and de-identify participant data before publishing. Nonblocking research is not a substitute for required technical acceptance.
