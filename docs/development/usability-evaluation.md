# sshOS 사용성 평가 상태

현재 사용자 인터뷰·비교 과업 시험·4주 pilot을 수행하지 않았다. 구현·자동 검사·개발용 패키지 결과로 수요나 반복 사용을 입증하지 않는다. 사용자 참여자를 확보한 후 [제품 계획 9절](../01-product-plan.md)의 기준으로 평가한다.

| 평가 | 수행 상태 | 정해진 관찰 기준 |
| --- | --- | --- |
| G0 문제 가설 | 미실시·참여자 미확보 | 최근3개월 SSH 파일·실행 경험자6명 중4명 이상이 실제 반복 불편을 설명 |
| G2 과업 사용성 | 미실시·참여자 미확보 | 12명·순서6명씩 교차 배정, 정상 과업 독립 완료10/12, 두 장애 과업의 결과·서버 식별9/12, 오서버 변경·거짓 완료0건 |
| G3 반복 사용 | 미실시·참여자 미확보 | 6명·4주, 사용 기회2회 이상인4명 이상 중3명 이상이 강제 없이2회 이상 사용 |

G2 과업에는 접속·탐색·보기·전송·프로그램 실행·느린 응답·단절 확인을 모두 포함한다. 평소 도구와 시오스에 같은 과업을 주고 미지원 업무와 불편을 기록한다. 참여자별 과업 완료·도움 요청·결과 해석·서버 식별을 관찰해 집계한다. 참여자의 실제 서버 계정·파일을 수집하지 않는다.

G3에서 사용할 기회가 부족하면 관찰 부족으로 기록한다. 숫자 기준 미달을 임의 제외하거나 성공 사례만 모아 가설 지지로 표시하지 않는다. 결과는 가설 지지·기각·관찰 부족으로 구분하며 원자료의 식별정보를 제거한 후 공개 범위를 참여자와 정한다.
